## Deformerz - A recreation of the Terep2 demo by Nagymathe Denes

This project aims to build a fully compatible modern version of Terep2 using [raylib](https://www.raylib.com)

Also serves as a test bed for reverse-engineering the data files and other aspects of the game.

The [Terep2 DAT Car Model Format](https://github.com/Zi9/Deformerz/blob/master/docs/TEREP2_DAT_car_model_format.md) is a result of this reverse-engineering effort.

> [!IMPORTANT]
> This repo contains and will contain only human written code
